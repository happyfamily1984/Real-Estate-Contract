# 계약서함 개발 노트 (새 세션이 이어서 작업할 때 먼저 읽기)

사용자와 대화로 정한 요구사항·결정을 모아 둔 문서. 코드만 봐서는 알기 어려운 "왜"를 적는다.

## 기본 원칙
- 사용자에게는 항상 한국어로 답한다. 커밋 메시지·주석·문서도 한국어.
- 전부 무료로: Firebase Spark 요금제(Auth·Firestore·Firebase AI), Gemini. Claude API 쓰지 않음.
- PC 없이 동작: GitHub Actions 가 APK 를 만들고 기본 브랜치에 푸시하면 릴리스 `app-v{번호}` 를 만든다.
  - 설치 파일 주소: `https://github.com/happyfamily1984/Real-Estate-Contract/releases/download/app-v{N}/contract-app-{N}.apk`
- 공개 저장소. 비밀값은 GitHub Secret (`KEYSTORE_PASSWORD`, `GOOGLE_SERVICES_JSON`). 서명 키는 암호화본만 커밋.
- 뒤로가기: 이전 행동(선택·수정·창) 취소 또는 이전 화면. 홈에서는 "앱을 종료하겠습니까?" → 예 = 종료.

## AI
- 모델은 사용자가 직접 확인해 정한 이름 그대로: `gemini-3.8-flash`, `gemini-3.1-flash-lite` (AI 설정에서 바꿀 수 있음). 임의로 바꾸지 말 것.
- 대안 순서: Firebase 모델 → 사용자가 넣은 Gemini API 키(휴대폰에만 저장) → 휴대폰 안 글자 인식(LocalAnalyzer). AI 가 다시 되면 UpgradeWorker 가 자동으로 다시 분석.
- 정리할 때는 사진 대신 숨겨 둔 핵심 텍스트(digest)만 보낸다.

## 계약 규칙
- 계약내용정리 한 줄 형식: "YY년 MM월 DD일 매매계약 매수 금액 …", 진행중인 계약에 "현재 진행중".
- 경매: 잔금납부일 = 취득일(불확실하면 "(예상)"), 잔금 = 취득금액. 분양: 분양금액 = 취득금액.
- 이해관계자: 등록한 이름이 계약 당사자로 나올 때만 표시, 여러 명 가능, 직접 수정 가능.
- 폴더 상태 진행중/완료 직접 수정 가능. 향후 일정: 6·3·1개월 전 알림, 만료된 진행중 임대는 갱신으로 추정.
- 계약관련서류(채권채무존재확인서 등, `docKind = "related"`): AI 분석 안 함, 정리·일정에서 제외.

## 업로드·옮기기
- 한 번에 파일 100개 / 100MB, 계약서 한 건 최대 50페이지. PDF·JPG.
- 폴더 밖에서 올린 계약서는 AI 가 폴더를 '제안'만 하고, 사용자가 "옮기기"로 확정할 때 폴더를 만든다(중복 폴더 방지).
- 옮긴 계약서·페이지는 목록에서 바로 사라져야 한다. 같은 파일은 SHA-256 지문으로 중복 차단("이미 옮겨진/올라간 계약서입니다").
- 홈 화면 카드·바둑판에는 사진을 넣지 않는다(바둑판은 이름만, 한 줄 3개).

## 이 클라우드 작업 환경에서 빌드하기
Maven Central 일부 주소가 막혀 있어 미러 스크립트를 쓴다.

    cd android
    ./gradlew -I tools/mirror.init.gradle testDebugUnitTest

릴리스 빌드는 GitHub Actions 에서만 한다(서명 키 비밀번호가 필요).
